Vault Sync

プライバシーポリシー

Vault Sync は、Obsidian の Vault を利用者自身の Google Drive と同期するプラグインです。このページは、Vault Sync が Google のユーザーデータをどう扱うかを説明します。

アクセスするデータ

Vault Sync は Google の https://www.googleapis.com/auth/drive.file の権限だけを求めます。アクセスできるのは、Vault Sync が作成したファイルとフォルダ、およびその内容と属性だけです。Google Drive のそれ以外のファイルは読み取れません。

データの使い方

取得したデータは、利用者の端末と Google Drive の間で Vault を同期するためだけに使います。広告、分析、機械学習の学習には使いません。

データの保存

  • ログインのトークンは、利用者の端末の中にだけ保存します。
  • 同期の状態は、利用者の端末の中にだけ保存します。
  • 同期したファイルは、利用者の端末と利用者自身の Google Drive に保存されます。

データの共有

Vault Sync は作者や第三者のサーバーを経由しません。作者が利用者のデータを受け取ることはなく、第三者に渡すこともありません。通信先は Google のサービスだけです。

データの削除とアクセスの取り消し

Google アカウントのサードパーティとの接続のページから、いつでも Vault Sync のアクセスを取り消せます。端末の中のトークンは、プラグインの設定画面でログアウトすると削除されます。Google Drive のファイルは、利用者が Drive から削除できます。

Google API サービスの利用

Vault Sync による Google API から受け取った情報の使用と移転は、Limited Use の要件を含む Google API Services User Data Policy に従います。
